# 💖 Interactive Friendship Day Web App

A cute, aesthetic, interactive, and mobile-responsive web application created to celebrate Friendship Day with soft pastel themes, floating background animations, interactive choices, polaroids, and music!

## ✨ Features

- **🌸 Pastel Aesthetic:** Soft glassmorphism UI with custom typography (`Pacifico` & `Fredoka`).
- **🎈 Floating Background Animations:** Floating hearts, stars, and sparkles.
- **💖 Multi-Stage Interactive Logic:**
  - Stage 1: Playful initial friendship question.
  - Stage 2: Upgraded "Best Friend" question with a dodging/running "Still No" button and growing "OF COURSE!" button.
  - Stage 3: Celebration page with a confetti burst.
- **📸 Polaroid Photo Grid:** Cute taped frame slots for memories.
- **🏷️ Sticker Badges:** Fun badges like *Partners in Crime*, *Late Night Maggie Gang*, etc.
- **🎵 Music Player & Selector:** Includes soft background melodies with an interactive modal to switch songs or paste custom links.
- **🤗 Tap for Hugs / Sparkles:** Interactive particle launcher.

## 🛠️ Built With

- **HTML5**
- **CSS3** (Flexbox, Grid, Animations, Glassmorphism)
- **Vanilla JavaScript** (DOM Manipulation, Canvas Confetti)

## 📝 Customization

To customize this project for your own friends:
1. Open `index.html`.
2. Replace photo URLs in the `<img class="polaroid-img">` tags with your own photo links.
3. Edit friendship quotes and sticker badge text inside the respective HTML sections.
